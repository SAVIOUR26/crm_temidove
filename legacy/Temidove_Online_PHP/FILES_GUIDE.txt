📊 DATABASE TABLES CREATED
──────────────────────────────────────────────────────────────────────────────

users table (Authentication)
├─ id: Unique identifier
├─ username: Login username (unique)
├─ password: Hashed password (bcrypt)
├─ email: User email (unique)
├─ full_name: Staff member name
└─ role: 'admin' or 'staff'

courses table (Available Courses)
├─ id: Unique course identifier
├─ course_name: Course title
├─ description: Course details
├─ price: Course fee in UGX
└─ duration_weeks: Course length

registrations table (Student Inquiries)
├─ id: Unique registration ID
├─ first_name: Student's first name
├─ last_name: Student's last name
├─ email: Student email
├─ phone: Contact phone
├─ course_id: Foreign key to courses
├─ status: 'waiting', 'started', 'completed', 'cancelled'
├─ inquiry_date: When inquiry was submitted
├─ assigned_to: Foreign key to users (staff assignment)
├─ notes: Internal staff notes
├─ start_date: When course started
└─ created_at/updated_at: Timestamps
